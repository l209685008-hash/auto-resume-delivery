# BOSS Candidate Greeting Assistant

Chrome Manifest V3 插件，用于在 BOSS 直聘推荐候选人页筛选“有明确工作经验且有相关行业经验”的候选人。人工启动后，插件会自动点击符合条件候选人的“打招呼”。只有页面状态变为“继续沟通/已打招呼”等成功状态，才会计入成功。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后的插件文件夹，里面应能直接看到 `manifest.json`。

## 使用

1. 打开 BOSS 直聘推荐候选人页面。
2. 点击浏览器右上角扩展图标。
3. “最多打招呼人数”最多 60。
4. 不勾选 `Dry Run 只筛选不点击` 时会真实点击“打招呼”。
5. 不勾选 `每个候选人逐个确认` 时会自动连续执行。
6. 点击“开始”后不要刷新页面；遇到验证码、登录、安全验证会自动停止。
7. Chrome 可能提示“此扩展正在调试此浏览器”，这是为了发出真实鼠标点击；运行结束后插件会释放调试连接。

## 规则

- 候选人卡片解析到明确工作经验，且命中当前职位相关行业经验即可通过；如果年限未识别但行业经历明显，也按宽松规则通过。
- “1个月、7个月、8个月、1年、2年、10年以上、1年3个月”通过。
- “应届/在校/无经验/经验不限”不通过。
- 运营助理：电商运营、新媒体运营、直播运营、平台运营、店铺/商品运营、淘宝/天猫/拼多多/抖音/快手/小红书/1688 等相关经历通过。
- 打包/电商打包员：电商、仓库、物流、打包、包装、配货、拣货、理货、发货、仓管、WMS、订单、售前售后等相关行业经历通过。
- 财务总监/财务主管：财务、会计、出纳、总账、成本、税务、审计、应收应付、报税、开票、记账、对账等相关经历通过。
- 本次运行最多打招呼 60 人，代码层硬上限也是 60。
- 默认运行间隔为 0.5-0.9 秒；如页面限制、网络慢或点击未确认增多，可在弹窗把间隔调大。
- 页面显示“继续沟通/已打招呼/沟通中”等状态后，才计入打招呼成功。
- 遇到验证码、登录、安全验证、账号异常、访问过于频繁等页面提示会停止。
- 不会绕过验证码或安全校验。
- 插件不会按年龄、出生年份、性别等个人属性筛选、排序、跳过或打招呼；自动条件只限于工作经验和相关行业经验。

## 审计

插件将事件写入 `chrome.storage.local`，可在弹窗点击“导出审计”生成 JSON 文件。核心事件包括：

- `RUN_STARTED`
- `CANDIDATE_EVALUATED`
- `DRY_RUN_MATCH`
- `GREETING_CLICKED`
- `GREETING_NOT_CONFIRMED`
- `GREETING_SKIPPED`
- `RUN_STOPPED_LIMIT_REACHED`
- `RUN_STOPPED_HUMAN_REQUIRED`
- `RUN_ERROR`

## 维护

BOSS 直聘页面 DOM 可能变化。如果扫描不到候选人或按钮，优先修改 `src/content/domSelectors.js` 中的选择器。
