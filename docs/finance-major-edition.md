# 财务关键词版（0.4.0）规则口径

本文件描述当前口径，取代 `finance-edition-spec.md` 中 0.2.x 的六项条件，
以及 0.3.0 曾使用的“财经类专业 + 12–24 个月经验”。

## 两条硬条件

1. **大专及以上 · 财务相关专业**：大专/专科/高职、本科/学士/硕士/博士，专业属会计、
   财务管理、财会、审计、税务、税收等。中专/中职/职高/技校/高中及以下不通过；
   金融、经济、统计、国贸、工商管理、计算机等不算。
2. **命中跨境电商关键词**：简历文本出现以下任一关键词即通过，不再计算经验月数。

```
跨境电商 跨境 亚马逊 amazon 海外仓 退税 出口退税 fba 保税仓 保税
独立站 速卖通 shopee lazada tiktok shop 阿里巴巴国际站 国际站
外贸 报关 进出口 结汇 外汇
```

两条都通过才是 `match`，否则 `reject`。没有第三种结果。

## 关键词判定细节

- 匹配范围：候选人卡片可见文本（已剔除岗位 JD 区块与教育经历行）+ 每条工作经历的
  公司、职位、描述。教育经历整行排除，否则“广东外语外贸大学”会命中“外贸”。
- 大小写不敏感：`AMAZON`、`Amazon` 均命中 `amazon`。
- 长词吸收短词：命中“跨境电商”时不再单独报“跨境”；命中“出口退税”不再报
  “退税”；命中“保税仓”不再报“保税”；命中“阿里巴巴国际站”不再报“国际站”。
- 证据区输出两部分：命中的关键词列表 + 首次命中的上下文原句（前后各截若干字）。
- 关键词表是 `src/content/financeRules.js` 顶部的 `KEYWORDS` 常量，增删即可生效；
  增删后需重新加载扩展。

## 与 0.3.0 的差异

| 项 | 0.3.0 | 0.4.0 |
| --- | --- | --- |
| 学历 | 本科及以上 | 大专及以上（0.5.2 起放宽） |
| 专业 | 财经类（含金融、经济、国贸、统计） | 财务相关（会计、财务、审计、税务、税收） |
| 经验 | 同一工作条目内本人财经职责，12–24 个月 | 简历出现跨境关键词即可，不看月数 |
| 跨境电商 | 仅作标注，不参与判定 | 是第二项硬条件的全部内容 |
| 结论 | match / reject | match / reject（不变） |

## 专业判定细节

- 逐词判定：教育行先按空白、`·`、顿号、逗号切词，再剔除校名/院系名词
  （以大学、学院、学校、中学、职校、技校结尾的词），在剩余词里找学历与专业。
  `上海立信会计金融学院 计算机科学与技术` 判为不属于财务相关；
  `某大学 会计学院 会计学` 通过，`某大学 会计学院 计算机` 不通过。
- 只有院系名、没有专业名（`某大学 会计学院 本科`）判为证据不足，不再把
  “会计学院”当作专业。
- `主修课程/核心课程/课程：` 之后的整段截断；含课程、培训、证书、考试、资格的
  词单独丢弃；`辅修/选修/自学` 开头的词整词丢弃；`主修会计学` 去掉前缀后仍算专业。
- `专升本/专转本/专接本` 视为本科层次；`非财务相关` 等明确否定直接不通过。
- `非财务相关`、`不是财务` 等明确否定直接判为不符合。
- 硕士/博士为财务相关时按通过处理：简历通常只展示最高学历，无法要求补证本科。
- 学历是否“已毕业”不再校验，只看专业是否财务相关。
- 学历门槛为大专：`大专/专科/高职` 与本科以上同等对待，中专及以下不通过。

## 不变的部分

- 年龄、性别、出生日期、婚育情况不参与解析、排序、判定或发送。
- 单个任务、单标签页归属；发送前落盘；结果不明不重试；连续三次未确认即停。
- 每轮最多扫描 100 人、最多 60 次打招呼尝试、30 分钟运行上限。
- 页面岗位无法识别时只允许扫描；岗位名称须含财务/会计/财经/审计/税务/金融。

## 需要留意的取舍

- 关键词只看“有没有提到”，不判断提到它的岗位是不是财务岗。一个会计专业、
  在简历里写了“对接亚马逊运营”的候选人也会命中。命中的原句会显示在证据里，
  便于人工复核。
- 反过来，只做纯国内业务、通篇没有跨境词的财务候选人会被判不符合，即使经验
  完全匹配。词表偏窄时可自行补充（如“海关”“信用证”“离岸”）。
- 关键词扫的是卡片可见文本，因此“个人优势”里写“了解亚马逊”也算命中，哪怕
  实际岗位与跨境无关。命中原句会显示在证据区。
